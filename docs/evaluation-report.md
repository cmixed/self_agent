# RAG 检索评估报告

- 数据集：`backend/app/evaluation/dataset/`（3 篇文档，7 条问答）
- 检索参数：top-k = 5，余弦相似度
- 说明：评估在临时向量库中进行，不污染个人知识库

## 汇总指标

| 指标 | 数值 |
| --- | --- |
| Hit@5（来源命中率） | 1.000 |
| 关键词覆盖率 | 1.000 |
| 来源精确率 | 0.333 |
| MRR（首个正确来源的平均倒数排名） | 0.905 |

## 结果解读

- **Hit@k** 反映「前 k 条结果中是否包含正确来源」，是 RAG 检索最关键的下限指标。
- **来源精确率** 在本文数据集上偏低属于预期现象：语料只有 3 篇文档，top-k=5 会把每篇文档的片段都召回，因此期望来源最多只能占 1/3。在真实大规模知识库中该指标才有区分度。
- **MRR** 对「正确来源排在第几位」敏感，适合观察排序质量而非仅看是否命中。
- 本套件只使用本地 Embedding 模型与向量库，不调用大模型，因此完全离线可复现；每次运行结果应当一致（受向量库浮点实现影响可能有极小波动）。
