# 检索增强生成（RAG）基础

检索增强生成（Retrieval-Augmented Generation, RAG）是一种把信息检索与大语言模型生成结合的
技术路线。它的基本流程分为两步：先根据用户问题从外部知识库中**检索**出相关文档片段，
再把这些片段作为上下文交给大语言模型**生成**回答。

RAG 的主要价值在于三点。第一，模型可以访问训练数据之外的知识，回答不再局限于参数中
记忆的内容。第二，外部知识库可以随时更新，因此回答具备时效性。第三，回答可以标注来源，
使用者能够核查依据，从而降低模型凭空编造的**幻觉**风险。

RAG 并不能消除所有错误：如果检索环节没有召回正确的资料，生成环节即使再强也无法给出
可靠答案。因此在 RAG 系统中，检索质量往往比生成质量更值得优先优化。
